# Research questions

1. Which operations already write stock, and which of them bypass a ledger?
2. Is a lot required for every item, or only for tracked items?
3. What does "negative stock" mean for each warehouse today?
4. Which reports read a cached balance, and how stale may they be?
5. What is the idempotency key for each caller: request id, order id, or both?
6. How is a transfer reversed, and who can approve the reversal?
7. What is the largest stocktake a single transaction must accept?
8. Which audit questions has an auditor actually asked in the last year?
