Here is the problem this solves. Two hundred thousand tokens into a session, most
of your window is tool output you already looked at once and will never need
again. That is not your prompt growing. That is your tools talking over each

So we built a ladder instead. Locate does the searching and returns a file and
a line, nothing more. Build does the writing. Each role gets its own model and
its own effort level, and every one of them is a plain data edit in a profile
file.

Our config is JSONC, which means comments and trailing commas are legal, and a
person editing their own file will absolutely add both. Our parser choked on a
trailing comma. It returned an empty object. And then the command that
regenerates your config merged onto that empty object and wrote your settings
back out deleted.
[[slnc 13000]]
No warning. No backup. Just a config that no longer had the key you added last
Tuesday.
[[slnc 9000]]
So here is the fix, on a file that still has that trailing comma and that
comment in it. It reads the text properly now. And notice it also keeps a
backup, because the one path that overwrites your file should never be the one
path with nowhere to go back to.
